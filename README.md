# Таня Эпик — портфолио

Сайт-портфолио: веб-разработка, дизайн и видеомонтаж.

## Структура

```
index.html            — весь сайт (разметка, стили, скрипты)
assets/fonts/         — шрифт Unbounded
assets/video/         — видео и постер первого экрана
assets/img/           — работы из каталога дизайна
assets/slides/        — слайды презентации «Кто владеет результатом?» и их миниатюры
.nojekyll             — чтобы GitHub Pages отдавал файлы как есть
```

## Как опубликовать на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `portfolio`).
2. Загрузи в него всё содержимое этой папки: `index.html`, папку `assets` и файл `.nojekyll`.
   В веб-интерфейсе: **Add file → Upload files**, перетащи файлы и папку, нажми **Commit changes**.
3. Открой **Settings → Pages**. В разделе **Build and deployment** выбери
   **Source: Deploy from a branch**, ветка **main**, папка **/ (root)**, нажми **Save**.
4. Через минуту-две сайт будет доступен по адресу `https://<твой-логин>.github.io/<имя-репозитория>/`.

Разделы открываются и по прямым ссылкам: `…/#code`, `…/#design`, `…/#editing`, `…/#contact`.

## Как заменить или добавить работу

Положи картинку в `assets/img/` и скопируй в `index.html` любой блок `<figure class="work" …>`,
поменяв путь к картинке, название и подпись. Атрибут `data-cat` отвечает за фильтр:
`poster`, `print`, `logo`, `cover`, `deck`, `digital`, `merch`.
